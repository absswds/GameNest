# v2.2.0 — 谁是卧底、跑得快、快问快答，按人数找游戏，画猜和锄大地修复

### 新功能

- **谁是卧底**：4–10 人，每人看到自己的词，轮流描述后投票。结算有每轮表格，电脑玩家三档，词库已扩充。
- **跑得快**：2–3 人，出完手牌者赢，倒计时按服务器剩余时间显示。
- **快问快答**：1–8 人抢答，题库 650 道，结算有表格，电脑三档，修复连对相关的信息泄露。
- **大厅按人数筛选**：分类下面多了一行“人数”，选 1 到 6 人以上，只列出这个人数能玩的游戏。选 1 人时会列出所有能单人玩的游戏。
- **贪吃蛇限时**：每局 3 分钟，时间到最长的蛇获胜。

### 优化

- **画猜**：笔画实时同步，只发增量；画家落笔时不再重建猜词输入框，手机键盘不会反复弹出；轮数可选，题库扩充，支持繁体猜词。
- **锄大地**：按港式规则重写牌型和大小比较，至少 3 人，A-2-3-4-5 顺子、同花顺、对手剩一张时必须出最大单张、按剩牌数 ×1/×2/×3 计分；累计分跨局保留。
- **等候室**：开始按钮旁不再和状态栏重复提示“等待所有玩家准备”；单人游戏不再显示“等待玩家加入”。
- **大富翁**：掷骰动画放慢，骰子总点数显示在骰子下方，关键事件弹出提示卡。
- **2048**：方块平滑滑到新位置，再播合并和新块出现动画。
- **机器人难度**：UNO、数字炸弹、贪吃蛇、跑得快用对打统计校准。UNO、数字炸弹和跑得快靠运气，困难最多只能赢随机玩家六到七成半，所以三档拉开的幅度比棋类小（简单约等于乱出）。贪吃蛇三档本来就拉得开（困难赢简单 92%）。

### 修复

- 服务器：玩家走子抛异常不再拖垮整个服务；WebSocket 消息限制大小和频率。
- iPhone Safari：大厅顶部区块不再消失。
- MCP：`get_canvas` 在画猜里能取到当前画面。
- 24 点单人局模拟不再卡住；国际象棋困难档计时测试放宽到 60 秒。

### New features

- **Undercover**: 4–10 players. Everyone gets a word, describes it in turn, then votes. Per-round results table, three bot tiers, larger word list.
- **Run Fast (Paodekuai)**: 2–3 players, first to empty their hand wins; the countdown follows the server clock.
- **Quiz Race**: 1–8 players buzzing in on 650 questions, results table, three bot tiers; a streak-related information leak fixed.
- **Lobby player-count filter**: a new "Players" row under the categories (1 to 6+). Choosing 1 lists every game you can play alone.
- **Snake Battle time limit**: 3 minutes per game; the longest snake wins when time is up.

### Improvements

- **Draw & Guess**: strokes sync live and only send increments; the guess box is no longer rebuilt while the drawer draws, so phone keyboards stay open; selectable round count, bigger word list, Traditional Chinese guesses accepted.
- **Big Two**: rewritten to Hong Kong rules (minimum 3 players, A-2-3-4-5 straight, straight flush, highest single when the next player has one card, x1/x2/x3 scoring); totals persist across games.
- **Waiting room**: no duplicate "waiting for everyone to be ready" text next to the Start button; solo games no longer say "waiting for players".
- **Monopoly**: slower dice roll with the total shown under the dice; key events pop up as cards.
- **2048**: tiles slide smoothly, then merge and spawn animations play.
- **Bot difficulty**: UNO, Number Bomb, Snake Battle and Paodekuai calibrated by self-play. UNO, Number Bomb and Paodekuai are luck-driven (Hard beats a random player only about 65-75%), so their tiers are closer together than in board games; Easy is close to random play.

### Fixes

- Server: an error in a player's move no longer takes the server down; WebSocket messages are limited in size and rate.
- iPhone Safari: the lobby header block no longer disappears.
- MCP: `get_canvas` returns the current picture in Draw & Guess.
- The 24 simulation no longer hangs in solo games; the Chess hard-bot timing test allows 60 seconds.
